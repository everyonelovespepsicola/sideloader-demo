# Privacy Policy for Sideloader

**Effective Date:** September 15, 2026

## 1. Data Collection and Usage
**Sideloader** ("the Application") does not collect, store, transmit, or share any personal user data or telemetry. All operations, application management tasks, and file transfers are performed strictly locally on your PC and connected target hardware.

## 2. Network Activity
The Application accesses external network resources solely for the following purposes:
- **Component Downloading:** Dynamically retrieving official developer platform utilities at runtime if not present on your local system.
- **Application Metadata:** Fetching public app details or open-source package information (such as F-Droid repository listings) upon user request.

No user identifiers, telemetry, device IDs, or tracking analytics are sent over the network.

## 3. Storage and Data Security
All application preferences, temporary logs, and cached metadata remain stored entirely on your local Windows file system under your user profile directory (`%LOCALAPPDATA%`).

## 4. Contact Us
If you have any questions or concerns regarding this Privacy Policy, please contact the developer via our official repository issue tracker at [https://github.com/everyonelovespepsicola/sideloader-demo](https://github.com/everyonelovespepsicola/sideloader-demo).
