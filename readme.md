**Sideloader** is the fastest, easiest 1-click desktop app manager to sideload games and apps onto **Meta Quest VR headsets, Fire TV, Android phones, and tablets**.

---

## ⚡ Key Features

- 📦 **1-Click Drag & Drop Sideloading**: Sideload `.apk` & `.xapk` packages instantly onto Meta Quest 2 / 3 / 3S / Pro and Android devices.
- 📶 **Wireless Wi-Fi ADB Pairing**: Auto-discover local mDNS broadcasting devices and pair wirelessly on Android 11+.
- 🛍️ **F-Droid Open-Source Store**: Browse, search, and install thousands of free open-source apps (NewPipe, Droidify, Termux, VLC).
- 🗂️ **Integrated File Manager**: Browse internal storage, push/pull files, and backup app data folders.
- 📱 **60FPS High-Speed Screen Mirroring**: Control your Android phone or Quest VR screen directly from your PC desktop with `scrcpy`.
- ⚙️ **Hidden System Settings**: Modify animation scales, enable ad-blocking private DNS, and fine-tune system flags.
